Entry for [The Absurd Clause Contest](https://make.fun/bounty/u-donrulezz-the-absurd-clause-contest-035cc0f1) on make.fun.

One line, 200 characters at most: an absurd clause hidden deep inside a terms-of-service agreement. A judge model reads the clauses in pairs and the funniest one takes the reward.

## Entry

> Section 14.2: The User hereby appoints the household's smallest spoon as Compliance Officer and agrees to tap it twice on the rim before accepting any amended terms.

## How it works

`main.ts` writes the clause to `/output/entry.txt` using Node.js (`node:fs`). Run with `node main.ts`.
